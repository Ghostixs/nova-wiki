Profiles

One Hermes install, 10 profiles. Each is a specialist with its own memory, credentials, and cron jobs; a single multiplex gateway ticks all of their schedules. Nova lives in the default profile and coordinates the rest. In practice: work in one area stays in that area, and each specialist keeps its own memory and credentials.

Integrations

  • MCP: Todoist for tasks, Notion for the job board and notes.
  • Google: Gmail, Calendar, and YouTube Music through one OAuth client.
  • Discord: a bot on a private server is the primary surface; cron feeds post to channels like #nova, #inbox, #jobs, #tech-news, and #things-to-do.

In practice: one assistant can reach tasks, notes, email, calendar, and chat without switching tools.

Automation

  • Multiplex gateway: one process ticks every profile's cron jobs; jobs catch up when the machine wakes.
  • Job search: runs as a kanban board with the jobs profile as the command center; matches that clear a defined filter surface in the #jobs feed for review.
  • Approval flows: desktop plugins turn unattended batch work into approve/deny popups, so nothing writes itself into memory unchecked.

In practice: schedules run on their own, and unattended batch work asks for approval before it writes anything.

Homelab

  • Runtime: Docker plus a WSL2 Ubuntu instance named Ubuntu-Nova, on the same laptop that runs Hermes.
  • Local AI: Nova runs right here on this laptop, with SearXNG for private web search.
  • Media and home: Jellyfin, Trakt, Home Assistant, Vaultwarden, and a Homepage dashboard.

In practice: everything runs on one laptop, so the data stays home.

Desktop plugins

Eight plugins extend the Hermes desktop app itself. The four Jacque built, from the memory inbox that gatekeeps what enters memory to session sections that organize the work board, are cataloged in the library; the rest ship with the app.
