Integrations

  • MCP: Todoist for tasks, Notion for the job board and notes.
  • Google: Gmail, Calendar, and YouTube Music through one OAuth client.
  • Discord: a bot on a private server is the primary surface; cron feeds post to channels like #nova, #inbox, #jobs, #tech-news, and #things-to-do.

Automation

  • Multiplex gateway: one process ticks every profile's cron jobs; jobs catch up when the machine wakes.
  • Job-scout heartbeat: a recurring scout pass that surfaces new matches to the #jobs feed.
  • Approval flows: desktop plugins turn unattended batch work into approve/deny popups, so nothing writes itself into memory unchecked.

Homelab

  • Runtime: Docker plus a WSL2 Ubuntu instance named Ubuntu-Nova, on the same laptop that runs Hermes.
  • AI serving: Open WebUI and SearXNG for local web search.
  • Media and home: Jellyfin, Jellyseerr, Sonarr, Radarr, Home Assistant, Vaultwarden, and a Homepage dashboard.

Desktop plugins

Eight plugins extend the Hermes desktop app itself: from the memory inbox that gatekeeps what enters memory, to session sections that organize the work board. See the plugin pages in the library for each one.
